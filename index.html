Vị trí vườn (thời tiết)

Thiết lập nhanh

Máy mới: dán chuỗi cấu hình (bắt đầu bằng DR27E1.) vào ô dưới rồi bấm Áp dụng, nhập mật khẩu là xong. Hoặc quét mã QR.
Máy đã cài: bấm Tạo mã cấu hình, đặt mật khẩu, rồi gửi chuỗi hoặc ảnh QR cho người mới.
Hướng dẫn thiết lập nhanh

Kết nối GitHub (GitHub Connection)

Tạo token (chỉ cần quyền gist) tại github.com/settings/tokens.
User ID, token và Gist ID chỉ lưu trong trình duyệt của thiết bị này. Dữ liệu chi tiêu vườn lưu trong file durian2027.json của Gist (secret).
Hướng dẫn kết nối GitHub (How to connect GitHub?)

Ngân sách tháng

Thông báo Zalo Thử nghiệm

Tính năng đang thử nghiệm: chưa kiểm chứng đầy đủ với Zalo Bot thật, tin nhắn có thể không đến hoặc không báo lỗi.
Tùy chọn. Điền đủ Bot token và Chat ID thì mới bật. Để trống thì app chạy bình thường, không gửi gì. Mỗi khoản chi thêm mới hoặc sửa gửi đúng 1 tin.
Chưa có Chat ID? Bấm mở getUpdates (trang chờ khoảng 30 giây), trong lúc chờ hãy nhắn 1 tin cho bot trên Zalo, rồi tìm chat → id.
Hướng dẫn kết nối Zalo (How to connect Zalo?)

Danh mục

Import từ CSV

File CSV (UTF-8) có dòng tiêu đề date,note,category,amount:
• date: 2026-11-01 hoặc 01/11/2026 (bắt buộc)
• note: nội dung (tùy chọn)
• category: danh mục, chưa có sẽ tự tạo; để trống = "Khác"
• amount: số tiền VNĐ > 0, vd 35000 hoặc 35.000 (bắt buộc)
Dấu phân cách , ; hoặc Tab đều được. Tiêu đề tiếng Việt (ngay, noi dung, danh muc, so tien) cũng nhận.
